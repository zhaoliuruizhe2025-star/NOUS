# NOUS Academic Foundation

## 1. Purpose and status

This document defines the approved future direction for an Academic Foundation / Framework Library. It does not authorize a framework database, runtime reasoning engine, sources, or UI.

NOUS should know the person deeply, but reason beyond the person’s past. Personal history provides context; academic frameworks provide structure; neither alone has authority over the user.

## 2. Framework humility

**Theory is a lens, not a verdict.** A framework must not become a diagnosis, a scientific claim merely because it is philosophical, or a source of authority because it is famous.

The library should distinguish empirical findings, therapeutic frameworks, interpretive psychological models, contested historical theories, philosophical lenses, and normative ethical frameworks. Their evidence status, limitations, and provenance are not interchangeable.

Potential sources include empirical, cognitive, social, and emotion psychology; behavioral science; decision theory; appropriately bounded CBT, ACT, and DBT; development/personality research where evidence supports it; philosophy and ethics; classic works; and modern reviews, systematic reviews, meta-analyses, and contemporary evidence.

## 3. Use in reflection

For deeper psychological explanation, apply **personal pattern first, theory second**:

```text
personal historical pattern + current evidence + relevant framework + uncertainty
  -> possible explanation
```

Explain hypotheses as hypotheses. Do not force a user into a theory or use academic terminology to make weak reasoning sound authoritative. Major interpretations should remain traceable to current evidence, relevant personal history, framework, evidence status, and uncertainty.

When a substantive psychological interpretation actually relies on an academic framework, briefly name that framework in the ordinary user-facing response—such as “From a decision-theory perspective…”—without turning the response into a bibliography or lecture. Do not name a theory merely to create rhetorical authority, and do not require a theory name when no academic framework is actually being used. Detailed provenance can remain internal or become expandable later; it is not a required first-beta structured UI.
